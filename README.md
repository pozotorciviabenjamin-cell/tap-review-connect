# TAP REVIEW Connect

Quiero crear un sitio web profesional, moderno y comercial para una marca argentina llamada TAP REVIEW, un emprendimiento de San Juan que ofrece tarjetas NFC personalizadas para negocios.

IMPORTANTE:
Quiero que el resultado parezca una página hecha por un diseñador/desarrollador web profesional para una empresa real. NO quiero que parezca una landing page genérica creada por inteligencia artificial. Evitar el típico estilo exageradamente tecnológico de las páginas de IA, exceso de gradientes, neones, glassmorphism, elementos flotantes innecesarios, textos genéricos o diseños que parezcan una plantilla.

La página debe sentirse:

* Profesional
* Premium
* Moderna
* Confiable
* Simple de entender
* Comercial
* Elegante
* Cercana
* Argentina
* Orientada a pequeños y medianos negocios

La web debe estar completamente optimizada para celulares, especialmente iPhone y Android, pero también debe verse excelente en computadora.
